Rendering the Gyroid

One implicit equation, a marching-cubes pass, and you get an infinite minimal surface that never intersects itself.

What is a gyroid?

The gyroid is a triply-periodic minimal surface — a surface that repeats in all three dimensions, has zero mean curvature everywhere (locally soap-film-like), and, remarkably, contains no straight lines and never self-intersects. It was discovered by Alan Schoen at NASA in 1970, and it keeps showing up in the real world: in butterfly wing scales, in block-copolymer nanostructures, and — because it’s strong, light, and fully connected — as a favourite infill pattern for 3D printing.

The math

There’s a beautifully compact approximation to the gyroid as the zero level-set of a single trigonometric field:

sin(x)·cos(y) + sin(y)·cos(z) + sin(z)·cos(x) = 0

Every point where that expression equals zero lies on the surface. Everything else is just sampling and extracting it.

The code

The whole thing is a short NumPy + scikit-image script: sample the field on a 50×50×50 grid over [−π, π]³, then run marching cubes at level 0 to pull the isosurface out as a triangle mesh and plot it.

grid_size = 50
x = np.linspace(-np.pi, np.pi, grid_size)
X, Y, Z = np.meshgrid(x, x, x)

gyroid = np.sin(X)*np.cos(Y) + np.sin(Y)*np.cos(Z) + np.sin(Z)*np.cos(X)

verts, faces, normals, values = measure.marching_cubes(gyroid, level=0)
ax.plot_trisurf(verts[:,0], verts[:,1], verts[:,2], triangles=faces, cmap='viridis')

Bump up grid_size for a smoother surface (at the cost of memory and time), or widen the sampling domain to tile more periods of the cell.
