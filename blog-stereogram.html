Seeing Through Magic Eye

What is an autostereogram?

An autostereogram is a single flat image that hides a 3D shape. It works by taking a narrow pattern and repeating it horizontally — but the repeat width is nudged slightly from column to column. When your eyes diverge (or cross) so that two neighbouring copies of the pattern fuse into one, those tiny shifts read as depth, and a 3D surface pops out of the noise.

That means the depth information is really there in the pixels, just encoded as local changes in the repeating period. If a human visual system can decode it, so can a computer — which is exactly what this tool does.

The pipeline

Given one autostereogram, the analyzer runs four stages:

  • Period estimation — measure the dominant horizontal repeat width (via autocorrelation), the baseline from which all depth is read.
  • Base texture recovery — reconstruct the single pattern tile that was tiled across the image.
  • Depth map — block-match each region against its shifted neighbour; the local disparity (how far the period drifts from the baseline) becomes the depth at that pixel.
  • 3D surface — lift the depth map into a mesh / point cloud, render it, and export to PNG or a Wavefront .obj.

Two ways to run it

The original is a PyQt5 desktop app in Python (NumPy, Pillow, Matplotlib). I then ported the whole pipeline to JavaScript so it runs as a live web app — 100% client-side, images never leave your machine. The heavy analysis runs in a Web Worker so the UI stays responsive, and the recovered surface is rendered in 3D with three.js. A built-in random-dot stereogram (SIRDS) generator is included so you can try it with zero setup.

# run the live web app locally
cd docs
python -m http.server 8000
# then open http://localhost:8000

Open the live version: generate a sample (or drop in your own stereogram) → tweak parameters → Analyze → inspect the base texture, depth map, and interactive 3D surface → export a PNG or .obj point cloud.
