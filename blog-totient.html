The Shape of Euler’s Totient

Computing φ(n) for every number up to N and plotting it — where the scattered points quietly draw the structure of the integers.

What is φ(n)?

Euler’s totient function φ(n) counts how many integers from 1 to n are coprime to n (share no factor with it other than 1). For a prime p, everything below it is coprime, so φ(p) = p − 1. For composite numbers it drops, depending on their prime factors.

Computing it

The clean way is straight from the prime-factorisation formula, φ(n) = n·∏(1 − 1/p) over the distinct primes p dividing n. The code implements exactly that with trial division:

def phi(n):
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

The tool computes φ(i) for every i up to a chosen N, caches the results to a CSV so repeat runs are instant, and plots φ against n with Plotly.

Why the plot is interesting

Plotted, φ(n) isn’t a smooth curve — it’s a cloud of rays. The primes ride along the top edge at φ(n) = n − 1; numbers with many small prime factors sink far below; and the whole thing has a fractal, self-similar texture that’s a direct fingerprint of how divisibility is distributed across the integers.

Why it matters

φ isn’t just pretty. It’s the backbone of RSA: for a modulus n = p·q, φ(n) = (p − 1)(q − 1), and that value is what lets you derive the private exponent from the public one. Euler’s theorem — aφ(n) ≡ 1 (mod n) for coprime a — is the engine underneath. Getting an intuition for φ is getting an intuition for public-key crypto.
