Postbase

Cybertalents · Cryptography · 50 points · Easy. The challenge provides a string of letters and numbers with the hint that it is not understood, of which the leading characters are corrupted:

R[corrupted]BR3tCNDUzXzYxWDdZXzRSfQ==

The trailing == and the character set identify the data as Base64. The suffix is intact, but the first few characters are unknown, so a direct decode fails. Because the plaintext is expected to begin with the token FLAG, the unknown prefix can be recovered by enumeration: candidate strings matching the known pattern are generated with exrex, each is decoded, and the single candidate whose decoded output begins with FLAG is accepted.

#!/usr/bin/env python3
import base64, exrex

def Base64_D(base64_message):
    message = base64.b64decode(base64_message.encode('ascii')).decode('ascii')
    if message[:4].upper() == "FLAG":
        print(message)

if __name__ == "__main__":
    B64hash = exrex.generate('R([A-Za-z0-9+])+BR3tCNDUzXzYxWDdZXzRSfQ==')
    for i in B64hash:
        try:
            Base64_D(str(i))
        except Exception:
            pass

The decode that yields a string beginning with FLAG is the flag.

Scattered

EOman 2022 · Cryptography · 80 points · Easy. The flag is distributed across many image files inside a zip archive, and must be reassembled. Each file has been renamed to the MD5 hash of its true name, and the true names follow the pattern r x c, that is, a row and a column coordinate matching the regular expression ([0-9]x[0-9]).

The solution first brute-forces every file name back to its coordinate by hashing each candidate from that small pattern space until the digest matches:

import os, hashlib, exrex, itertools
from PIL import Image

def md5_f(hash):
    for i in itertools.count(1):
        for s in exrex.generate('([0-9]x[0-9])'):
            if hashlib.md5(s.encode('utf-8')).hexdigest() == hash:
                return s

Each file is then renamed to its recovered r x c .jpg coordinate. The number of rows and columns and the tile dimensions are read from the recovered names, a blank canvas of the full size is created, and every tile is pasted into its grid position, reconstructing the complete image and revealing the flag.

for i in range(rows):
    for j in range(cols):
        file = str(i) + 'x' + str(j) + '.jpg'
        if file in files:
            img = Image.open(file)
            result.paste(img, (j*width, i*height))

result.show()

Special Summation

EOman 2022 · Coding · 35 points · Easy. The task is to sum all odd integers between two bounds, with the condition that any running total ending in a zero is discarded rather than carried forward. For the flag, the bounds are 10 and 1000.

7 + 9 = 16 16 + 11 = 27 27 + 13 = 40 (skipped: ends in 0) 27 + 15 = 42 42 + 17 = 59

The running total is updated only when the new sum does not end in zero, which is tested with sum % 10 != 0:

def sum_odd(start, end):
    odds = [x for x in range(start, end) if x % 2 != 0]
    total = 0
    temp = odds[0]
    for i in range(1, len(odds)):
        total = temp + odds[i]
        if total % 10 != 0:
            temp = total
    return total

sum_odd(10, 1000)

Count Words

EOman 2022 · Coding · 40 points · Easy. The flag is the number of words in the supplied file whose embedded digits sum to exactly 10.

t5?@h3ro2usands has 5 + 3 + 2 = 10 (counted) o4?@f6r has 4 + 6 = 10 (counted) w1?@e2rr1e has 1 + 2 + 1 = 4 (not counted)

Each word is scanned for digit characters, those digits are summed, and the word is counted when the sum equals 10:

def sum_digits_string(s):
    return sum(int(x) for x in s if x.isdigit())

with open("dump.txt") as file:
    count = 0
    for line in file:
        for word in line.split():
            if sum_digits_string(word) == 10:
                count += 1
    print(count)

Longest Word

EOman 2022 · Coding · 15 points · Easy. The flag is the longest word in the attached article. The file is read, split into tokens, and the maximum by length is selected:

with open('article.txt') as f:
    words = [y for x in f.readlines() for y in x.split()]
    longest = max(words, key=len)
    print(longest, "and it is", len(longest), "characters long")

CTF22: Escape Encoding and Strange Strings

EOman 2022 · Mixed. Two short sub-tasks.

Escape encoding. The flag is given as a list of decimal character codes, recovered by mapping each code to its character:

flag = [89, 111, 117, 71, 111, 116, 84, 104, 101, 70, 108, 64, 103]
print("".join(map(chr, flag)))
# YouGotTheFl@g

Strange strings. Two Base64-encoded files are provided. Decoding both and keeping only the characters that agree at the same index in each reconstructs the flag:

file1 = base64.b64decode(open('file1.txt').read()).decode('utf-8')
file2 = base64.b64decode(open('file2.txt').read()).decode('utf-8')
flag = "".join(file1[i] for i in range(len(file1)) if file1[i] == file2[i])
print(flag)
# Flag{YoU_DiD_GooD_MaTcHinG}
