Scope

Each challenge is documented in its own directory, containing a short written analysis and a runnable solution. The objective is not simply to record the flag but to provide a clear account of how the challenge was solved: the observation that proved decisive, the vulnerability or mathematical property it exploited, and code sufficient to reproduce the result.

Structure of each write-up

  • Reconnaissance. What the challenge provides and what it is actually asking.
  • Key observation. The single insight that renders the challenge tractable.
  • Solution. A clean script that produces the flag from start to finish.

The complete collection, in which each directory contains its own analysis and solution script, is available in the WriteUps repository.
